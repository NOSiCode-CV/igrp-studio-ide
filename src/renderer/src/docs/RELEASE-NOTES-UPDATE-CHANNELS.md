# Release notes – Canal de atualizações (Beta / Stable)

Use este texto nas release notes quando publicar uma versão que inclua a funcionalidade de canais de atualização.

---

## EN (English)

### New: Update channel (Beta / Stable)

You can now choose which update channel to use:

- **Stable** – Only stable releases. Recommended for production use.
- **Beta** – Includes pre-releases (e.g. `0.1.0-beta.10`) for early access to new features.

To change the channel: open **Settings** → **About** → **Update channel**, then select Stable or Beta. The next update check will use the selected channel.

---

## PT (Português)

### Novo: Canal de atualizações (Beta / Estável)

Agora pode escolher o canal de atualizações:

- **Estável** – Apenas versões estáveis. Recomendado para uso em produção.
- **Beta** – Inclui pré-lançamentos (ex.: `0.1.0-beta.10`) para acesso antecipado a novas funcionalidades.

Para alterar: abra **Definições** → **Sobre** → **Canal de atualizações** e selecione Estável ou Beta. A próxima verificação de atualizações usará o canal escolhido.
