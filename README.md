## Project Setup

### Requirements

```bash
$ node -  "^20.19.0 || ^22.13.0 || ^23.5.0 || >=24.0.0". Got "22.12.0"
```

### Install

```bash
$ yarn
```

### Development

```bash
$ yarn dev
```

### Build

```bash
# For windows
$ yarn release:win

# For macOS
$ yarn release:mac
or
$ yarn release:mac:x64

# For Linux
$ yarn release:linux
```
